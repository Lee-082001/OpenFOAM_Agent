# OpenFOAM Agent v5.0.5

## Scope

v5.0.5 fixes the pre-commit artifact-lifecycle regression exposed by two-region blockMesh solid cases. It is a maintenance release on top of v5.0.4.

## Fixes

- Separates Agent-authored required inputs from required artifacts generated by compiled native producers.
- Uses `native_tool_contracts.json` `mesh_dependency_outputs` plus execution-scope binding to classify deferred native outputs; there is no filename-only `polyMesh` exemption.
- Allows `constant/<region>/polyMesh/*` entries in the final required manifest when a scoped `blockMesh`/other declared producer is actually compiled.
- Keeps those same paths as genuine missing inputs when no producer exists, preserving fail-closed behavior for imported/pre-existing meshes.
- Retained-candidate repair capsules now expose `deferred_native_required_files` separately and never instruct the model to author those outputs.
- Adds a dedicated bounded candidate-replan capsule so a large retained candidate cannot fall back to the full generic engineering context and overflow the 18k model budget.
- Progress telemetry now distinguishes `authoredRequired` from `nativeGeneratedExpected`.

## Regression coverage

The v5.0.5 tests cover:

1. a battery/heater two-scope blockMesh plan whose final required manifest includes both regions' `polyMesh/{points,faces,owner,neighbour,boundary}` outputs;
2. negative ownership behavior when no compiled producer exists;
3. retained-candidate repair excluding native-generated mesh outputs from `missing_required_files`;
4. bounded candidate-replan context under a deliberately oversized retained manifest/artifact.

The controller still keeps the full EngineeringPlan and retained candidate as authority. Model-facing partitions are projections only.
