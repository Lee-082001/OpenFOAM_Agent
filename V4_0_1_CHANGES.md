# OpenFOAM Agent v4.0.1

v4.0.1 is the release designation for the completed v4 audit-hardening implementation previously staged as v4.0.0rc2.

The implementation includes the v4 audit work for execution approval and subprocess budgets, confirmed-condition preservation, region-aware validation, authoring syntax evidence, completion contracts, asset tracking, checkpoint/resume, local MPI contracts, dependency-aware mesh invalidation, resource/isolation policies, and generalized post-processing validation.

The release designation change does not claim additional native OpenFOAM, MPI, or OS-isolation validation beyond the verification evidence shipped with this package. Those environment-dependent checks remain explicitly identified as unverified where applicable.
